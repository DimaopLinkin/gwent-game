# Game rules schema
## game_rules (один объект, не таблица)
Числовые параметры партии и колоды. Значения берутся только из `docs/hand/main.md`.
- crystals int: кристаллы (жизни) каждого игрока в начале партии (раздел 1, «Кристаллы»)
- starting_hand_size int: сколько карт берётся при раздаче (раздел 3, шаг 4)
- max_redraws int: сколько карт можно заменить при пересдаче (раздел 3, шаг 5)
- min_squad_cards int: минимум карт отрядов в колоде, герои считаются (раздел 2.1)
- max_special_cards int: максимум специальных карт в колоде (раздел 2.1)
